# Mimo projects Git control repository

This repository exists solely to provide four independent Git worktrees for the user's Mimo projects. Each project uses its own branch and checkout under `D:\anything\Mimo_Worktrees`. The `.git` metadata is shared here as required by Git worktrees. Do not develop an app in this control directory and do not merge project branches into each other.

Project source, data, dependencies and outputs belong only in their corresponding worktree. Personal recordings, photos, datasets, credentials, caches and build outputs are ignored by Git.

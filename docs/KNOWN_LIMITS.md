# 已知限制

1. **单机单用户**  
   仅监听 `127.0.0.1`，无账号体系、无云同步、无多设备实时合并。

2. **图表量纲**  
   多指标叠加时不同单位共用坐标轴，只适合比较走势，不适合比较绝对高度。

3. **相关分析**  
   皮尔逊相关仅为描述性统计，样本量小时不稳定，不表示因果。界面已标注样本数与免责声明。

4. **单位换算**  
   导入时支持：体重 `kg / lb / 斤`，睡眠 `小时 / 分钟`。其他单位需在导入前自行换算，或先映射到自定义指标。

5. **日期解析**  
   自动识别常见格式；异常日期（如 `2026-02-30`）会记为错误行并跳过，不会静默写入。

6. **CSV 方言**  
   使用 Python `csv` 引擎，支持逗号/分号/制表符。极复杂的引号嵌套可能需先清理。

7. **备份恢复**  
   `replace` 模式会删除当前日记录后写入备份；不会自动回滚。请先导出当前 JSON。

8. **月报图表**  
   Markdown 导出以表格与文字为主；完整图表在网页/打印版中。Obsidian 通过 Markdown 导入。

9. **端口冲突**  
   默认 8764；占用时自动递增到 8783。不修改防火墙与其他项目。

10. **磁盘**  
    无第三方依赖；`data/`、`exports/` 随记录增长。当前工作区占用可在交付报告中查看。

11. **不是医疗设备**  
    睡眠主观评分、鼾声负担等为自记录描述，不能替代医疗诊断。
